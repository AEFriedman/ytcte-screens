- r2 non-blocker (post-reload gap, no last-good Hebrew date): still present, still backlogged. First-load and post-watchdog-reload both show a blank Hebrew line until the first fetch returns.

Spec match: I checked each behavior clause against the code. Layout split, single-value rotation hook, viewport readout default-on, deck embed with chrome cropped, explicit America/New_York via `Intl`, 12-hour clock, day/date, Hebcal civil-day (no `gs=on`, so midnight-based — matches), last-good-on-failure, fixed timer always running underneath, poll-failure falls back with a visible degraded indicator, load timeout retry, clock watchdog reloading the page, single config block containing every value the spec enumerates. All present. No unstated capability added.

No blockers.

Non-blockers:
- **Enabling change detection later will require making the deck file publicly link-shared**, because a bare API key can only read `files.get` on a public file. That is a broader exposure than publish-to-web (the source deck becomes downloadable/copyable by anyone holding the file id, which is committed here in plain sight). Nothing exposed this cycle. Worth a yes/no from the user before that flag is ever flipped — product decision, not mine.
- Rotation hook is not quite the one-value fix the spec claims: `applyRotationBox` swaps the wrapper's box correctly, but every internal size is in `vh`, which keeps referring to the real viewport height rather than the rotated box. At 90deg the clock type would come out roughly 44% small on a 1920x1080 render. Ships at 0deg, so inert now.
- `#viewport-debug` and `#degraded-indicator` sit outside `#viewport-wrapper`, so they would not rotate with the content. Arguably right for the debug readout, arguably wrong for the degraded indicator.
- The clock watchdog and the initial `setDeckSrc()` are both registered near the end of the IIFE. Any throw during init above them (e.g. an `Intl` constructor rejecting the timezone) leaves a page with no recovery path at all and a placeholder deck for up to 10 minutes. Low likelihood on Chromium; noting because unattended self-recovery is the point of that code.
- Inverse of the above: a deterministic throw inside `updateClock` produces a page that reloads itself every ~15-20s indefinitely. Loud rather than silent, so acceptable, but it is a loop with no ceiling.
- Hebcal is called with zero-padded `gm`/`gd` ("09", "04") rather than integers. Almost certainly parsed fine; the reference implementation used the `date=YYYY-MM-DD` form instead. Cheap to confirm against the live endpoint.
- Deck iframe has no `sandbox` attribute, so the framed Google origin could navigate the top window. Trusted source, negligible risk, but `sandbox` is the belt-and-braces option if it doesn't break the embed.
- `deckChromeCropPx: 60` and the 80/20 split are both still unverified against the real panel, as the spec says. Per CLAUDE.md, none of this is verified until it is on the actual screen.
- Process: r1 backlog items 1 (deck page-setup resize) and 2 (confirm Cast orientation, then flip the readout off) are only partially reflected in `BACKLOG.md`.

Security review: PASSED. No secret, token, key, PII, or non-public internal URL in the file. All external URLs are built with `URL`/`searchParams.set`, so no unsafe interpolation. The one piece of external data rendered — Hebcal's `hebrew` field — goes through `textContent`, not `innerHTML`. The only `innerHTML` write is a constant empty string. Both external fetches abort on a timer, so a stalled request surfaces as the degraded state rather than hanging silently. No auth, no writes, no third-party system reached beyond two public read-only GETs. The change-detection path fails closed (gated on flag AND non-empty key).

Backlog items noted:
1. Before enabling change detection, confirm the deck file may be made publicly link-shared, given its file id is committed publicly.
2. Rotation hook: `vh`-based sizing does not follow the rotated box, so a 90deg correction needs a second adjustment.
3. Decide whether the degraded indicator should live inside the rotating wrapper.
4. Init-order fragility: watchdog and first deck load register late in the IIFE, so an early throw leaves no recovery.
5. Verify zero-padded `gm`/`gd` against the live Hebcal converter, or switch to the `date=YYYY-MM-DD` form.
6. Consider `sandbox` on the deck iframe.
